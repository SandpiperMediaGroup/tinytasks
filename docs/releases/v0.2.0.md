# TinyTasks v0.2.0

Faster task entry and editing, Lists & Chats navigation, and desktop setup improvements.

## Changes

- Double-click empty space below your tasks to add another task, or empty sidebar space to create a list.
- Keep task metadata inline on wide layouts, with centered row controls and direct editors for due dates, priority, agents, and lists.
- Show completed/total subtask counts and hide completed subtasks with the Completed display property.
- Enable a sidebar with My Desk, Today, Upcoming, All, and Lists & Chats. It hides below 720px and returns when the window widens.
- Move tasks and their subtasks between lists by dragging, right-clicking, or clicking the list name.
- Customize list icons with 80 outline symbols, or restore the list's original agent icon.
- Check for new GitHub releases daily or manually in Settings, then open the release download page.
- Copy the local MCP configuration and executable path from Settings.

Existing task files remain compatible. Empty lists are preserved in the markdown file.

## Downloads

This release includes a **Windows x64 installer**, **Windows portable ZIP**, **universal Mac DMG**,
and **universal Mac ZIP**, with SHA-256 checksums.
The Windows binaries are unsigned. Run the setup executable, or extract the ZIP to a permanent
folder and run `tinytasks.exe`. The installer installs WebView2 if needed; portable users need
the Microsoft Edge WebView2 runtime installed. Settings provides the executable path and MCP config.

The **universal Mac DMG and ZIP** support Apple silicon and Intel Macs. The app and DMG are
Developer ID signed, separately notarized by Apple, and carry stapled tickets. Open the DMG,
drag **TinyTasks.app** to **Applications**, eject the image, and launch `/Applications/TinyTasks.app`.
The ZIP contains the same app. Use `/Applications/TinyTasks.app/Contents/MacOS/tinytasks` with
`mcp` for agent connections. Verify all downloads against `SHA256SUMS.txt`.

The Mac downloads were added from the same unchanged `v0.2.0` source commit as the Windows
release. Existing Windows binaries are unchanged.

## Verification

Rust tests, the real MCP protocol against isolated task/state folders, and the remote UI interaction
suite passed. UI checks include responsive layout, row alignment, editing and moves, release-check
states, and normal/slowed/frame-by-frame motion review. Native Windows WebView/installer interaction
was not performed for the Windows release.

For the Mac build, Rust tests, the real MCP smoke test, and the UI interaction suite passed locally.
The packaged Mac executable also passed the MCP smoke test with isolated state. Final ZIP and DMG
checks verified universal architecture, signatures, stapled tickets, Gatekeeper acceptance, and
packaged contents. The installed app and Settings were visually checked on Apple silicon.
An Intel Mac was not available for runtime testing.

Updates download manually; this release does not add an automatic installer or Sparkle integration.
