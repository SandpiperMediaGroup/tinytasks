# TinyTasks v0.3.6

Plan your day in My Desk, review an agent's suggested arrangement, and schedule tasks directly on a rolling timeline.

## My Desk

- One desk for the current day, with start times and optional durations that do not change task due dates or list membership. The arrangement clears on the next day; the tasks stay in their lists.
- Agents can propose a complete arrangement for your review. Accept or decline it with one pair of actions; agents cannot accept it on your behalf.
- A rolling timeline shows the next six hours, or twelve on wide windows. Overlapping tasks stack, and the lamp marks the current-time line. Hover the timeline to reveal the current time.
- Drag a task onto the timeline to schedule it in 15-minute increments. A rotary picker lets you adjust the start, end, or entire block, with live timeline previews. Clear the time with one button.
- Scheduled tasks group into Morning, Midday, Afternoon, and Evening. Untimed tasks stay in Unscheduled. Times sit inline when space allows and wrap beneath the title in narrower windows.
- The desk's subtle background changes with the time of day. The plus button creates a new task inline.

## List refinements

- Task context-menu actions preserve your scroll position.
- Dragging a task shows a preview beside the cursor.
- Tasks have one list or chat home; list grouping stays consistent with the sidebar.
- Individual lists and chats can show completed tasks when the completed display property is enabled.
- List separators are inset without moving checkboxes. Row hover reveals controls without highlighting the whole row; a small scribble indicates nonblank details.
- Agent attribution is read-only in the app.
- Windows toolbar titles use the available space instead of being prematurely truncated.

## Agent compatibility

Existing task files remain supported. Daily desk arrangements are stored as metadata alongside the Markdown tasks.
The MCP `set_desk` shortcut now creates a pending suggestion rather than immediately replacing the accepted desk.
Agents should read `get_desk` and use `suggest_desk` with today's date and the complete proposed arrangement.
See the [My Desk guide](https://github.com/SandpiperMediaGroup/tinytasks/blob/v0.3.6/docs/my-desk.md).

## Downloads

**macOS — Apple silicon and Intel:** Open `TinyTasks-0.3.6-universal-macos.dmg` and drag TinyTasks to Applications.
The ZIP contains the same app. Both the app and DMG are Developer ID signed, separately notarized by Apple, and have stapled tickets.

**Windows x64:** Run `TinyTasks-0.3.6-windows-x64-setup.exe`, or extract the portable ZIP to a permanent folder and run `tinytasks.exe`.
The installer installs WebView2 when needed; the portable app requires the Microsoft Edge WebView2 runtime.
Windows binaries are unsigned, so Windows may warn about or block the download.

Verify downloads with `SHA256SUMS.txt`. Updates are installed manually. Settings provides the executable path and MCP configuration.
