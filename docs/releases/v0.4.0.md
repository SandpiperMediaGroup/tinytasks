# TinyTasks v0.4.0

More room for task details, quieter lists, and a small way to answer agent questions without leaving TinyTasks.

## Tasks and lists

- Turn sorting off independently of grouping. Drag tasks within a group to save their order.
- Read one expanded task branch at a time, with consistent paragraph spacing and details that resize without clipping.
- Open named or plain links directly from detail chips. Hover a chip to see its destination.
- Narrow rows give the title more width and keep the controls beside the agent/list on the second line. Checkboxes align with the title.
- Row controls follow lamp, details, subtask count, time, and more actions. Hover reveals desk membership in ordinary lists; subtask mode stays visible.
- Right-click the sidebar to create a list or archive genuinely empty lists. Successful cleanup stays quiet.
- Dragging preserves scroll position, and Clear time is a labeled action.

## My Desk and agents

- Building and Working status indicate when an agent is preparing your day.
- TinyTasks basics opens a separate reference window explaining lists, task rows, and My Desk.
- Agents can discover and reuse existing lists and tasks, with stable identities and retry-safe writes.
- Agents may publish a question in task details through MCP. Answer it in TinyTasks; the agent polls for the saved response. This is opt-in and does not mirror native Claude Code, Codex, or OpenCode prompts.

## Compatibility

Existing Markdown files and legacy MCP tools remain supported. Manual root order uses optional `@order` attributes; subtask `@position` is unchanged. Stable task identities, planning status, questions, and response receipts use additional metadata in the same task file. Preserve this metadata when editing files directly. No connector hooks or automatic agent resume are installed.

## Downloads

**macOS, Apple silicon and Intel:** Open `TinyTasks-0.4.0-universal-macos.dmg` and drag TinyTasks to Applications. The ZIP contains the same app. The app and DMG are Developer ID signed, separately notarized, and carry stapled tickets.

**Windows x64:** Run `TinyTasks-0.4.0-windows-x64-setup.exe`, or extract the portable ZIP and run `tinytasks.exe`. The installer installs WebView2 when needed; the portable app requires WebView2 already installed. Windows binaries are unsigned.

Verify downloads with `SHA256SUMS.txt`. Updates are installed manually. Settings provides the executable path and MCP configuration.

## Verification

Rust, real MCP protocol, and browser UI regression checks cover task ordering, list hygiene, desk planning, links, questions, and resizing. Packaged binaries receive architecture, version, and MCP checks. Mac downloads receive signature, notarization, ticket, Gatekeeper, and content checks.

Native Windows desktop/installer interaction and Intel Mac runtime testing were not performed. The local Mac review app was reviewed on Apple silicon; the final task-reorder gesture passed automated browser checks, but native drag automation was unavailable.
