# TinyTasks v0.4.1

Archive empty lists now includes lists containing only completed tasks.

- Cleanup archives named lists with no unfinished tasks or subtasks, regardless of completion age. Personal stays available.
- Completed history, notes, and agent source attribution are preserved in the archive. Lists containing any unfinished work stay active, including across duplicate headings.
- Cleanup remains silent and uses the existing recoverable archive transaction.
- The cleanup menu now uses a broom icon with proper spacing before its label.

## Downloads

**macOS, Apple silicon and Intel:** Open `TinyTasks-0.4.1-universal-macos.dmg` and drag TinyTasks to Applications. The ZIP contains the same app. The app and DMG are Developer ID signed, separately notarized, and carry stapled tickets.

**Windows x64:** Run `TinyTasks-0.4.1-windows-x64-setup.exe`, or extract the portable ZIP and run `tinytasks.exe`. The installer installs WebView2 when needed; portable users need WebView2 already installed. Windows binaries are unsigned.

Verify downloads with `SHA256SUMS.txt`. Updates are installed manually.

## Verification

Rust and browser UI checks cover cleanup eligibility, completed history, unfinished children, duplicate sections, source preservation, repeated cleanup, and quiet navigation updates. Packaged Mac and Windows binaries pass MCP checks; final download digests are verified against GitHub.

The Mac package is checked on Apple silicon. Intel Mac runtime and native Windows desktop/installer interaction were not tested.
